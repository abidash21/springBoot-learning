Dependency Injection - Don't create your own dependency but get your dependency
                     - A class should ask what it needs and not build everything itself
                     - Without it the class is responsbile for creating the object it needs
                     
There are two types of DI
1. Constructor Injection - Dependencies are provided through the class constructor
2. Setter Injection - Dependencies are provide through setter method
3. Field Injectino - Dependencies are injected directly into the fields using @Autowired


IOC - Inversion of control
- Withoug DI, class has the control to create object
- With DI, Spring container has the control to create objects and inject one into another.
  The control is inverted from application to spring container

=> IOC is the principle. DI is the approach to achieve IOC.
=> Spring framework has athe IOC container. The IOC container create objects, manage objects and connects object together.

Java -> Objects
Spring IOC container -> Beans
