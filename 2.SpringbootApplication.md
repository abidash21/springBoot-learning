Maven Life Cycle:
1. Clean Life Cycle
  i. clean → Deletes all files generated by previous builds (such as the target/ directory), ensuring a fresh build.
2. Default Life Cycle
  i. validate → Checks whether the project structure and pom.xml are correct and all required information is available.
  ii. compile → Compiles the project's source code (src/main/java) into bytecode (.class files).
  iii. test → Runs unit tests (using frameworks like JUnit) without packaging the application.
  iv. package → Packages the compiled code into a distributable format such as a JAR or WAR.
  v. verify → Performs additional quality checks to ensure the packaged application is valid, which are in pom.xml plugins
  vi. install → Installs the packaged artifact into the local Maven repository (~/.m2/repository) so other local projects can use it
  vii. deploy → Uploads the final artifact to a remote Maven repository for sharing with other developers or servers.
3. Site Life Cycle
  i. site → Generates project documentation, including reports, Javadocs, test results, and project information as a website.
